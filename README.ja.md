# Mini Keyboard Studio

[English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [Español](README.es.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md)

小さなキーボードを、自分らしく。Mini Keyboard Studioは、キー・ダイヤル・照明を編集し、USBでキーマップを書き込むローカルmacOSアプリです。

**[macOS Apple Silicon版をダウンロード](https://github.com/kyungtaek/mini-keyboard-studio/releases/latest)** · [開発ガイド](docs/development.md)

英語・韓国語・日本語・スペイン語・簡体字中国語・繁体字中国語に対応。**ファイルと共有**またはアプリのメニューで言語を変更できます。

![Mini Keyboard Studioのキーマップ編集画面](docs/images/studio-editor.jpg)

## 主な機能

- **3つのレイヤー。** キーやダイヤルに、キー入力、修飾キーの組み合わせ、マクロ、メディア操作、マウス操作を割り当てられます。
- **ショートカットを探して割り当て。** VS Code、Slack、Google Meet、cmux、Chrome、Claude、システム操作、Forza Horizon 4、Modern Warfare 4の参考一覧を検索し、分かりやすい機能名とともに保存できます。
- **置き方に合う向き。** 机の上でのキーボードの向きに合わせて、レイアウトを回転できます。
- **キーごとのLED設定。** 15色と**消灯**から選び、レイヤー共通のLEDモードを設定できます。
- **ローカル保存と共有。** キーマップの保存、JSONの読み込み・書き出し、プロファイルを含むリンクの共有に対応。編集とローカルファイルはオフラインで使えます。
- **確認しながら書き込み。** 書き込み前にキー設定をバックアップし、保存値を再読み込みして確認します。内蔵の入力診断も利用できます。
- **メニューバーに常駐。** ウィンドウを閉じても、必要なときにメニューバーから編集画面を開けます。

![キーごとのLEDパレットとレイヤーモード](docs/images/studio-led.jpg)

## 使い始める

1. [Releases](https://github.com/kyungtaek/mini-keyboard-studio/releases/latest)からApple Silicon用DMGをダウンロードし、アプリを**アプリケーション**へ移動して開きます。
2. USBデータケーブルでキーボードを接続し、**キーボードを接続**を選びます。
3. 内蔵サンプルまたは新しいキーマップを開きます。キーやダイヤルに機能を割り当て、必要に応じて色とレイヤーのLEDモードを設定します。
4. キーマップを保存し、準備ができたら**デバイスに適用**を選びます。ファイルを開いたり、参考にするアプリを変えたりするだけでは自動適用されません。

任意のGitHubキーマップカタログには、GitHub認証を使用します。内蔵サンプルとローカルのキーマップにGitHubアカウントは不要です。ゲーム用ショートカットは割り当ての提案なので、ゲーム内の設定と合わせてください。

## 対応デバイス

現在実機で確認済みなのは、USB **514C:8850**の**16キー・3ダイヤルMini Keyboard**と、テストしたファームウェアです。他のモデルのレイアウトも候補として用意していますが、すべてを実機で検証したわけではありません。

LEDモードの見た目はすべて確認済みではないため、**0〜5**の番号で表示します。モード変更が見えるまでUSBの再接続が必要な場合があります。一部の色変更は即座に反映されることを確認しています。再読み込みで確認できるのは保存値であり、すべての発光効果ではありません。キーマップの適用は手動で行い、フォーカス中のアプリに応じた自動切り替えは行いません。
