# Mini Keyboard Studio

[English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [Español](README.es.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md)

작은 키보드를 나에게 맞게 바꿔 보세요. Mini Keyboard Studio는 키·다이얼·조명을 편집하고 USB로 키맵을 적용하는 로컬 macOS 앱입니다.

**[macOS Apple Silicon용 다운로드](https://github.com/kyungtaek/mini-keyboard-studio/releases/latest)** · [개발 가이드](docs/development.md)

영어·한국어·일본어·스페인어·중국어 간체·중국어 번체를 지원합니다. **파일·공유** 또는 앱 메뉴에서 언어를 변경할 수 있습니다.

![Mini Keyboard Studio 키맵 편집기](docs/images/studio-editor.jpg)

## 주요 기능

- **3개 레이어 편집.** 키와 다이얼에 일반 키, 조합키, 매크로, 미디어·마우스 동작을 지정합니다.
- **단축키 찾아서 할당.** VS Code, Codex, Claude, 시스템 기본, Forza Horizon 4, Modern Warfare 4의 참고 목록을 검색하고 기능 이름과 함께 저장합니다.
- **책상에 맞는 방향.** 키보드를 놓은 방향에 맞춰 화면 배치를 회전합니다.
- **키별 LED 설정.** 15색과 **꺼짐** 중에서 고르고, 레이어 전체의 LED 모드를 지정합니다.
- **로컬 저장과 공유.** 보관함, JSON 가져오기·내보내기, 프로필을 담은 공유 링크를 제공합니다. 편집과 로컬 파일은 오프라인에서 사용할 수 있습니다.
- **확인하며 적용.** 쓰기 전에 키 설정을 백업하고 저장값을 재읽어 검증합니다. 내장 키 입력 진단으로 입력도 살펴볼 수 있습니다.
- **메뉴 막대에서 사용.** 창을 닫아도 메뉴 막대에서 필요할 때 편집기를 다시 엽니다.

![키별 LED 팔레트와 레이어 모드](docs/images/studio-led.jpg)

## 시작하기

1. [Releases](https://github.com/kyungtaek/mini-keyboard-studio/releases/latest)에서 Apple Silicon용 DMG를 내려받아 앱을 **응용 프로그램**으로 옮긴 뒤 실행합니다.
2. USB 데이터 케이블로 키보드를 연결하고 **키보드 연결**을 선택합니다.
3. 기본 샘플이나 새 키맵을 엽니다. 키·다이얼을 선택해 기능을 할당하고, 필요하면 키 색상과 레이어 LED 모드를 정합니다.
4. 키맵을 저장하고 준비되면 **장치에 적용**을 누릅니다. 파일을 열거나 단축키 참고 앱을 바꾸는 것만으로 자동 적용되지는 않습니다.

선택 기능인 GitHub 키맵 카탈로그는 GitHub 인증을 사용합니다. 기본 샘플과 로컬 키맵에는 GitHub 계정이 필요하지 않습니다. 게임 단축키는 바인딩 제안이므로 게임 내 설정과 맞춰 주세요.

## 지원 장치

현재 실물로 검증한 장치는 USB **514C:8850**의 **16키·3다이얼 Mini Keyboard**와 테스트한 펌웨어입니다. 다른 모델 배치는 후보로 제공하며 모든 모델을 실물로 검증한 것은 아닙니다.

LED 효과가 모두 검증된 것은 아니므로 모드는 **0~5**로 표시합니다. 모드 변경은 USB를 다시 연결해야 눈에 보일 수 있고, 일부 색상 변경은 즉시 반영되는 것을 확인했습니다. 재읽기 성공은 저장값을 확인하며 모든 시각 효과를 보장하지는 않습니다. 키맵은 수동으로 적용하며, 포커스된 앱에 따라 자동 전환하지 않습니다.
