# Mini Keyboard Studio

요청: MINI_KEYBOARD를 REA로 조사하고, 웹에서 키맵을 만들고 저장·공유하며 USB 장치에 적용한다. CoD4는 사용 예시이며 게임 프로필 자동 적용은 요청 범위에서 제외한다.

## 구성

- 설치 없는 정적 웹앱. Chromium WebHID로 장치 설정용 vendor collection에 직접 연결한다. HTTPS 또는 localhost에서 제공한다.
- 16키·3다이얼·3레이어를 시각적으로 편집한다. 키, 조합키, 순차 매크로와 해석 가능한 미디어·마우스 동작을 지원한다. 알 수 없는 원본 동작은 유지한다.
- 버전이 있는 JSON 파일은 특정 장치 원본 보고서와 분리한다. 가져오기 검증, 로컬 보관함, 파일 내보내기, URL fragment 공유를 제공한다. 서버 계정이나 공개 게시판은 만들지 않는다.
- 첫 연결은 브라우저 장치 선택 창을 사용한다. 이후 적용 버튼 한 번으로 전체 백업 저장, 변경된 레코드 기록, commit, 재읽기 검증을 수행한다. 실패 시 원본 복원을 시도하고 성공 여부를 구분한다.
- 실제 장치의 식별·보고서 크기·레이어/동작 ID를 검증한다. 전체 설정을 읽기 전 쓰지 않는다. 모델 변경, 펌웨어 갱신, 기기 초기화는 구현 범위에서 제외한다.

## 접근 방식

네이티브 앱 재작성은 설치가 필요하다. 로컬 브릿지는 브라우저 지원을 넓히지만 별도 실행 프로세스가 필요하다. 요청한 웹 설정 경험을 위해 직접 WebHID 방식을 선택한다. 기존 앱과 같은 통신 동작을 재구성하되 실행 성공을 실제 저장 성공으로 간주하는 동작은 재현하지 않는다.

## UI

루트 `design.md`의 Spotify 기반 디자인을 따른다. 배경은 #121212, 작업 패널은 #181818, 도구는 #1f1f1f이며 흰색과 #b3b3b3 텍스트를 사용한다. #1ed760은 저장·적용·편집 상태에만 사용한다. 로컬 Helvetica Neue/한국어 시스템 폰트와 pill 버튼, 원형 컨트롤을 사용한다.

- 좌측 보관함: 새 키맵 버튼, 저장된 키맵 목록, 구분선을 둔 파일·공유 도구, 템플릿·백업 순서다. 파일 가져오기/내보내기/공유가 키보드의 세로 공간을 차지하지 않는다.
- 중앙 작업면: 작은 제목·저장 행, 모델·방향, 레이어, 물리 키보드, 레이어 복사, 장치 읽기·적용 바다. 연결 시 현재 키·다이얼 동작을 읽어 표시하며 초안과 실제 값을 구분한다.
- 우측 편집기: 선택한 키의 동작 입력과 장치의 현재 동작을 보여준다. 긴 설명은 도움말 툴팁으로 옮긴다.
- 1050px 이상 너비·620px 이상 높이에서는 54px 헤더와 남은 viewport 높이로 작업면을 계산한다. 키보드는 실제 stage의 너비와 높이 중 작은 배율로 맞춰 회전·다른 모델도 영역 안에 배치한다. 본문을 `overflow:hidden`으로 자르지 않는다. 긴 라이브러리와 편집 오류는 각 영역에서 스크롤할 수 있다.
- 더 작은 창과 모바일은 문서의 자연스러운 세로 스크롤을 허용한다. 방향 전환은 전체 보드·다이얼 위치를 회전하고 키·다이얼 글자는 역회전하여 정방향을 유지한다.
- 상태·LED는 보조앱 연결에서만 제공하는 별도 수동 테스트 dialog다. 열 때 보조앱의 규칙 사용 상태를 OFF로 동기화한다. 토글 변경도 보조앱에 즉시 동기화하며 실패 시 불확실 상태와 오류를 표시한다. configure만으로 LED를 쓰지는 않는다.

### 컴팩트 배치 확인

2026-10-24 Chrome 실제 viewport 1600×733에서 문서 높이 942→733px, 헤더 74→54px, 제목 행 54→32px, 장치 바 하단 906→710px로 확인했다. 8개 모델×4방향 32개 조합 모두 문서 높이 733px, 가로 넘침 없음, 보드가 stage 안에 들어감을 확인했다. body/html의 overflow는 visible이며 숨겨서 잘라내지 않는다. 모바일 390px도 가로 넘침 없이 자연스러운 세로 스크롤을 허용한다. 실제 localhost 연결 화면은 부모 검증에서 현재 장치의 75개 동작 표시, 270도 방향 및 매크로 편집 상태로 같은 viewport 높이를 유지했다.

## 증거 경계

REA 원본 식별 SHA-256: `6f330a43fc9493d8f76e112b08c054d7c896a0d628d2e41bbfd701dbedfd6f4f`.
Qt x86_64 및 hidapi imports는 REA로 확인했다. 네이티브 디컴파일 엔진은 아직 없으며 설치 승인을 요청했다. 원본 앱 실행과 장치 쓰기는 아직 하지 않았다. 현재 USB 설정 인터페이스는 보이지 않고 Bluetooth MINI-KEYBOARD 입력 인터페이스만 확인됐다.

## 검증

프로파일 검증/직렬화, 보고서 프레이밍, 전체 백업 검증, 쓰기 순서·readback·롤백을 자동 테스트한다. 브라우저에서 키 편집, 3레이어, 파일 가져오기/내보내기, 보관함, 공유 링크, 새로고침 유지, 오류 상태를 확인한다. 모의 장치 검증과 실제 USB 설정·전원 재연결 후 유지·동시 키 입력 검증은 별도로 기록한다.
