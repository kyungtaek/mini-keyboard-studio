# Mini Keyboard Studio 0.6.0

## Changes

- English, Korean, Japanese, Spanish, Simplified Chinese and Traditional Chinese UI, native menus and dialogs. Language selection persists across launches.
- Built-in function names follow the selected language. Custom keymap names, explicit action labels, key combinations and JSON remain literal.
- USB presence is enumerated once per second. Removing the selected keyboard clears the connected indicator and disables device operations; uncertain enumeration is shown as unavailable.
- Presence checks never send configuration reports. An interrupted key-write transaction retains its backup and lease; explicit recovery verifies the original device before restoring that backup, including a changed USB path or stale handle.
- Six product-focused README translations with two unedited screenshots of the shared editor UI.

## Validation

- JavaScript: 132 tests passed, covering locale parity, dynamic/reversible translation, label preservation, event ordering, connect/disconnect races and existing keymap flows.
- Python: 58 tests passed, including unplug detection, zero configuration I/O during status checks, owner/expired recovery and wrong-device rejection.
- Independent code review: no remaining release blockers.
- Developer ID signature with hardened runtime and secure timestamp; strict deep verification passed.
- Apple notarization accepted for the final DMG. App and DMG tickets stapled and validated; Gatekeeper accepts both as `Notarized Developer ID`.
- The packaged helper launches and reports `connected: false`, `connectionState: disconnected` without a keyboard. Packaged source was compared with the final renderer and connection changes.
- Six-language native menu/dialog switching was inspected in a separate temporary user-data directory. Screenshots use the real editor with sample data; they do not demonstrate physical USB application.

## Distribution

macOS Apple Silicon (arm64), stable tag `v0.6.0`. Release assets include signed/notarized DMG, ZIP containing the stapled app, final update metadata/blockmaps and SHA-256 checksums.

Existing key and LED configurations are not rewritten by this update. The live unplug/replug transition should still be confirmed with the user's physical keyboard; automated transport tests and an unplugged launch are the evidence for the new connection fix.
