# Mini Keyboard Studio 0.6.1

Fixes the function layout appearing unchanged after applying a device rotation.
The previous apply step moved actions back to their old screen positions,
cancelling the visible rotation. Keys and functions now rotate together while
keeping their physical USB IDs, dial assignments and per-key LED slots intact.
Existing key combinations do not need to be entered again.

The confirmation dialog describes this behavior in all six languages. Pure
orientation changes can correctly report zero physical key writes; existing
explicit draft edits are still applied through the normal backup/readback path.

Validation: 132 JavaScript tests and 58 Python tests pass. The regression uses
16 distinct A–P assignments, verifies the actual apply payload and stored draft,
and checks all four orientations, rectangular layouts, preserve actions and LED
bindings. Browser geometry confirms that a left turn changes the top row from
A B C D to D H L P. A simulated device verifies the apply step; no test keymap was
written to the user's physical keyboard.

Distribution: macOS Apple Silicon, stable `v0.6.1`, Developer ID signed and Apple
notarized. Existing user profiles and backups are preserved during installation.
