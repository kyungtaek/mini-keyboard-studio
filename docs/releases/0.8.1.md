# Mini Keyboard Studio 0.8.1

## Changes

- General-purpose keymap editor: Codex session control, HUD, reserved trigger handling and status LEDs are disabled and excluded from distributed app files. Existing saved user keymaps remain intact.
- Add selectable Mac shortcut catalogs for Slack, Google Meet, cmux and Chrome. Expand real macOS defaults including Mission Control, screenshots, window management and app switching; remove fabricated system app-launch bindings.
- Drag keys onto each other to swap their assignments.
- Replace select, rotation, encoder and LED-off glyphs with consistent SVG assets.
- Restore and verify a pending temporary LED backup on the same device before applying profile lighting; report connection, lease and capability failures separately.
- Clear all known editable entry slots before encoding shorter assignments. This prevents stale modifier usages from prior mappings entering the full-slot write stage. Raw backups and preserve actions remain exact.
- Update shortcut translations and six-language README app lists.

## Validation

- Release source snapshot: 144 JavaScript tests and 58 Python fake-device tests passed. Additional unshipped Codex experiments remain local and are outside this release source snapshot.
- User confirmed Chrome Back and Mission Control operate normally after stale-entry cleanup. All 75 active assignments were preserved and all three layers passed readback.
- Installed-app apply saved 25 key/dial actions and lighting for two layers with verified readback during the preceding LED-recovery fix.
- Distribution ASAR source matches the current fixes and contains no Codex runtime, personal backups, credentials or research PoC payloads.

## Distribution

macOS Apple Silicon (arm64), stable tag `v0.8.1`. Developer ID signed app and DMG; Apple notarization and stapling results are recorded with release artifacts. Installing the app does not automatically overwrite hardware mappings.
